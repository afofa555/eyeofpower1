# Глаз Силы afofa555 (NeoForge 1.21.1)

Мод: предмет "Глаз Силы afofa555" надевается на голову, клавиша H (на русской раскладке Р) открывает меню сил:
1. Остановка времени (всё замирает, кроме владельца Глаза).
2. Чёрная дыра (засасывает мобов и игроков, кроме владельца; блоки остаются; попавших уносит в бездну).

Рецепт (верстак):
 песок душ | незерит | песок душ
 золото    | череп скелета | золото
 незерит   | песок душ | незерит
